### Changed

- Native Windows/Linux AMD64/ARM64 builds, tests and package names share one target contract;
  test archives carry validated source, tool and binary identities, and release assembly requires
  the complete package, SBOM and native runtime matrix.
- Optional update hints select a compatible package for the running binary and distribution
  format, retaining the Release page when identity or asset metadata cannot establish a match.
- Third-party licence notices include dependencies for every native release target.
- An explicit absolute `P4KX_FOLDERS_ROOT` isolates profile, cache and data folders on every
  platform; native window and package verification uses it to protect the user's real profile.
