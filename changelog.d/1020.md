### Added

- Linux: the window runs on X11 and Wayland with Vulkan and a GL fallback, takes its file dialogs
  from the desktop portal and copies to the system clipboard. The repository carries a desktop
  file and an icon set in `packaging/linux`. `P4KX_SMOKE_FRAMES=<n>` makes `p4kx-gui` draw `n`
  frames and exit, to check an installation without a user.
