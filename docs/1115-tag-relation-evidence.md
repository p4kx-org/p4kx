A skipped Tag relation reports its actual TagPathIncoming: the physical owning Record, Root or Child role, and original stored array ordinal. Null and malformed prefixes do not renumber later occurrences.

During that Record's canonical read, the Export receiver binds each non-null relation item to its same-read OriginalFlowFields fact and ExampleBodyCapture. The deferred receipt remains owned after the borrowed tree is released. Later skip events select that receipt by the actual physical position, typed role and original ordinal. These keys route already admitted evidence; they do not create it.

The retained field label uses the actual declaring field and array context. SourceType uses the owning original Header selector. Target GUIDs use the existing Reference policy: original Reference words are payload, weak links retain their admitted target/header and caller contributions, and dangling GUIDs use the actual error parameter. Malformed non-reference items retain an absent target.

Every selected receipt checks the actual input, inventory and Record owner before removal. Only retained diagnostic bodies materialize contributions before the report's existing single Health-text seal. Equal text atoms never replace the body's own occurrence origin.

The receipt map holds one deferred candidate per non-null original relation item and shares its source frame and interned text. The primary Tag projection reuses its existing fact index and capture frame; the separate dependency consumer creates one local index during its actual canonical callback. This describes storage and work, not a peak-memory guarantee. Tag projection limits are separate and unchanged.
