# Shield generators have physical configuration rows

Each selected `SCItemShieldGeneratorParams` component has one schema-v3 configuration
identified by its original Record and Components position. The row publishes the existing
shield numbers and authored reserve, electrical resistance, stun, resistance and absorption
inputs. Unprojected original members remain available through the existing source-value arena.
Every stored array slot is identified by authored order. A named mapping requires original
schema or declaration evidence.

The item variant fingerprint uses the existing compact serialization, including the shield
projection in its original position. Catalog serialization uses the canonical configuration
table for shield data and the remaining item stat fields for their existing consumers.
