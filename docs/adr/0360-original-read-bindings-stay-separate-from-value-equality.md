# Original read bindings stay separate from value equality

Canonical trees and resolved References retain their actual borrowed DataForge owner;
loadout file operations pair original admission with their read and parse outcomes.
Consumers validate these original operations instead of reconstructing authority from
matching GUIDs, positions, paths, values or serialized descriptions. This keeps format
crates independent from Archive services and avoids a second lookup or decode.

Value equality and canonical serialization remain descriptive. FieldStorage preserves
the actual declaration without becoming a transferable source authority; genuine whole
result clones retain their private original binding. Cached loadout observations reuse
the original outcomes without inventing another operation or the current caller's
selection. The [input API](../dataforge-input-origin.md#canonical-read-ownership) defines
these boundaries; [per-datum contributions](0357-source-encryption-provenance-is-explicit-per-data-value.md)
remain a separate output obligation.
